# DiagnostiX

DiagnostiX is an AI-powered disease prediction web application that helps users identify possible diseases based on selected symptoms. The platform uses machine learning models to analyze symptoms and provide disease predictions through an intuitive user interface.

## Features

- Disease prediction based on user-selected symptoms
- Machine learning powered diagnosis assistance
- Interactive and user-friendly interface
- Fast and accurate symptom analysis
- REST API integration between frontend and backend
- Responsive design for desktop and mobile devices

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Python
- Flask

### Machine Learning
- Scikit-learn
- Pandas
- NumPy

## Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/DiagnostiX.git
cd DiagnostiX
```

## Backend Setup

1. Navigate to the backend directory:

```bash
cd Backend
```

2. Create and activate a virtual environment:

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux/macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the Flask server:

```bash
python app.py
```

The backend server will run on:

```text
http://localhost:5000
```

## Frontend Setup

1. Navigate to the frontend directory:

```bash
cd Frontend
```

2. Install dependencies:

```bash
npm install
```

3. Start the React development server:

```bash
npm start
```

The frontend application will run on:

```text
http://localhost:3000
```

## How It Works

1. Users select symptoms from the available symptom list.
2. The selected symptoms are sent to the Flask backend.
3. A trained machine learning model processes the symptom data.
4. The model predicts the most likely disease.
5. The prediction is displayed instantly on the React frontend.
